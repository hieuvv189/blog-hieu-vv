# Blog Hiếu VV

Website cá nhân của Hiếu VV, dựng bằng Jekyll và chạy trên GitHub Pages.

## Viết bài mới

Thêm file `_posts/YYYY-MM-DD-ten-bai.md` với frontmatter:

```yaml
---
layout: post
title: "Tiêu đề bài"
date: YYYY-MM-DD HH:MM:SS +0700
---
```

Đẩy lên nhánh `main` là GitHub Pages tự build và đăng.
